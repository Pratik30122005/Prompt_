As discussed, below is a summary of the key topics and action items that I will be working on:
1. Model Selection Criteria
Understand when it is appropriate to use a higher-capability AI model instead of a smaller model.
Identify the factors that influence model selection, such as task complexity, reasoning requirements, response quality, cost, and latency.
Analyse how using a higher AI model improves prompt responses and in which scenarios the improvement justifies the additional cost.
2. Prompt Evaluation Framework
Study different approaches for evaluating prompt quality.
Understand the evaluation parameters, including Accuracy, Consistency, Business Alignment, Safety, Cost, and Performance.
Explore how these metrics help determine whether a prompt is ready for production.
3. AI Skills
Study what an AI Skill is and how it is developed.
Understand how prompts can be converted into reusable skills.
Learn how the same prompt or business use case can be organised into reusable skills for different workflows.
4. ROI of Extended Thinking
Analyse the Return on Investment (ROI) of enabling Extended Thinking.
Identify scenarios where Extended Thinking provides measurable value and where it may introduce unnecessary cost and latency.
Compare its benefits against the additional computational expense.
5. Practical Demonstration
Find a suitable implementation or sample code  to demonstrate these concepts practically.
Execute the same use case using different AI models/settings and compare the outputs.
Document the differences in reasoning quality, response accuracy, execution time, and overall cost to better understand the practical impact of model selection.


Accuracy – Correctness of the response
Completeness – Whether all task requirements are addressed
Relevance – How directly the response answers the task
Instruction Following – Compliance with the given instructions and format
Consistency – Logical and factual consistency of the response
Hallucination Control – Avoidance of unsupported or fabricated information
Reasoning Quality – Quality of logic, analysis, and problem-solving
